# AstraScanner Functional Tests

## Тест 1: Автосохранение облака при остановке сканирования

### Цель
Проверить, что накопленное облако автоматически сохраняется в проект при нажатии "Стоп".

### Шаги
1. Запустить приложение
2. Создать новый проект (Файл → Создать новый)
3. Нажать "Сканирование"
4. Сканировать объект в течение 10-20 секунд
5. Нажать "Стоп"
6. Проверить вкладку "Проект" - должен появиться скан с именем `scan_YYYYMMDD_HHMMSS`

### Ожидаемый результат
- [ ] Скан появился в списке сканов
- [ ] Облако отображается в окне просмотра
- [ ] Количество точек > 0

## Тест 2: Накопление на поворотном столе

### Цель
Проверить режим накопления при включенном поворотном столе.

### Шаги
1. Создать новый проект
2. Включить чекбокс "Поворотный стол"
3. Установить режим "Накопление"
4. Установить интервал 5 сек, количество 3
5. Нажать "Сканирование"
6. Дождаться завершения 3 циклов
7. Нажать "Стоп"

### Ожидаемый результат
- [ ] После каждого тика количество точек увеличивается
- [ ] В списке сканов отображается накопленное облако
- [ ] Облако объединяет данные со всех 3 сканирований
